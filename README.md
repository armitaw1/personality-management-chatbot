# Personality Management Chatbot | چت‌بات ارزیابی شخصیت

A simple Python chatbot that evaluates the user's personality preferences
in Project Management and Human Resources.

یک چت‌بات ساده با زبان پایتون که با پرسیدن چند سؤال،
میزان تناسب کاربر را با مدیریت پروژه و مدیریت منابع انسانی بررسی می‌کند.

## Features | امکانات

- دریافت نام کاربر | Getting the user's name
- پرسیدن سؤالات شخصیتی | Asking personality-based questions
- اعتبارسنجی پاسخ‌ها | Input validation
- محاسبه درصد تناسب | Calculating compatibility percentages
- نمایش نتیجه نهایی | Displaying the final result

## Technologies | تکنولوژی

- Python
- Google Colab

## How to Run | نحوه اجرا

Run the Python file and answer each question by entering 1 or 2.

فایل پایتون را اجرا کنید و برای پاسخ به هر سؤال فقط عدد 1 یا 2 را وارد کنید.

## Project Purpose | هدف پروژه

This project was created to practice basic Python concepts such as
input, conditions, loops, validation, and scoring.

این پروژه برای تمرین مفاهیم پایه پایتون مانند ورودی، شرط‌ها،
حلقه‌ها، اعتبارسنجی و امتیازدهی ساخته شده است.
